# Position Sizing Calculator

A single-page position sizing calculator based on Van Tharp's R-multiple method. It accounts for per-trade risk, portfolio heat, a per-trade capital cap, available cash, and a configurable maximum number of open positions.

Defaults include a ₹3,00,000 account size, a 20% per-trade capital cap, an 8% portfolio heat cap, and a maximum of five open positions.

## GitHub Pages

This repository is a static site. GitHub Pages can serve it directly from the `main` branch root.
